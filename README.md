# Sun VPN

**Быстрый VPN-клиент для Windows** с установщиком, автообновлением и обходом блокировок.
Работает с подписками в форматах VLESS/Reality, Hysteria2, Xray, Shadowsocks, Clash, sing-box и другими.

## Скачать

Последняя версия — в папке [`downloads`](downloads):

| Файл | Для чего |
|------|----------|
| **`Sun-VPN-<версия>-Windows-x64-setup.exe`** | Установщик (рекомендуется): ярлыки, удаление через «Приложения» Windows, автообновление. |
| `Sun-VPN-<версия>-Windows-x64.exe` | Переносная версия без установки (тоже обновляется сама). |
| `Sun-VPN-<версия>-Windows-x64.zip` | То же в архиве. |
| `Sun-VPN-<версия>-source.zip` | Полный исходный код, из которого собираются сборки. |

Рядом с каждым файлом лежит `.sha256` — контрольная сумма для проверки.

> При первом запуске Windows SmartScreen может показать «Неизвестный издатель» —
> нажмите **«Подробнее» → «Выполнить в любом случае»**. Приложение запускается с правами
> администратора, поэтому Windows покажет запрос UAC.

## Возможности

- **Форматы подписок:** VLESS, VMess, Trojan, Shadowsocks (+ плагины), Hysteria2, TUIC, AnyTLS,
  WireGuard, SSH; ссылки и подписки v2rayNG / Hiddify / Clash / sing-box / Streisand / HAPP.
- **Протоколы и транспорт:** Reality, TLS, XHTTP, WebSocket, gRPC, HTTPUpgrade, H2, маскировка
  Hysteria (salamander), UDP port hopping, закрепление сертификата, шифрование VLESS.
- **Режим выбранных приложений:** пропускать через VPN только нужные программы (например, браузер),
  через системный прокси — совместимо с zapret, без TUN и прав администратора для этого режима.
- **Автообновление:** приложение само проверяет новые версии, показывает изменения, скачивает
  с проверкой SHA-256, устанавливает и перезапускается, восстанавливая подключение.
- **Интерфейс:** анимированные темы, вкладка «Локации» с избранным и фильтрами, живой список
  соединений, статистика скорости.

## Как собирается

Сборка Windows выполняется автоматически в GitHub Actions на настоящей Windows/MSVC из
`downloads/Sun-VPN-<версия>-source.zip` (проверяется SHA-256). Workflow прогоняет тесты,
собирает portable EXE и установщик NSIS, проверяет установку/обновление/удаление и публикует
файлы вместе с `latest.json` (его читает встроенное автообновление). Сторонние ядра
sing-box и Xray — официальные закреплённые версии, их лицензии и исходники включены в сборку.
