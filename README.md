# Sun VPN

**Быстрый VPN-клиент для Windows и Android** с установщиком, автообновлением (Windows) и обходом блокировок.
Работает с подписками в форматах VLESS/Reality, Hysteria2, Xray, Shadowsocks, Clash, sing-box и другими.

## Скачать

Всё лежит в папке [`downloads`](downloads). Актуальная версия указана в [`latest.json`](downloads/latest.json).

| Файл | Для чего |
|------|----------|
| **`Sun-VPN-<версия>-Windows-x64-setup.exe`** | Windows: установщик (рекомендуется) — ярлыки, удаление через «Приложения», автообновление. |
| `Sun-VPN-<версия>-Windows-x64.exe` | Windows: переносная версия без установки (тоже обновляется сама). |
| **`Sun-VPN-<версия>-Android-arm64.apk`** | Android 7+: приложение для телефонов (процессор arm64 — почти все современные). |
| `Sun-VPN-<версия>-source.zip` | Полный исходный код, из которого собираются все сборки. |

Рядом с каждым файлом лежит `.sha256` — контрольная сумма для проверки.

### Windows

При первом запуске SmartScreen может показать «Неизвестный издатель» — нажмите **«Подробнее» → «Выполнить в любом случае»**. Приложение запускается с правами администратора, поэтому Windows покажет запрос UAC.

### Android

1. Скачайте `.apk` на телефон и откройте его. Android попросит разрешить установку из этого источника — разрешите.
2. При первом подключении появится системный запрос на создание VPN-подключения — подтвердите.
3. Весь трафик телефона идёт через выбранный сервер. Автообновления в APK нет: новую версию скачайте и установите поверх.

Ограничения Android-версии: серверы, которым нужен Xray (XHTTP, Hysteria с маскировкой), не подключаются; режим «выбранные приложения» и режимы прокси недоступны; задержка измеряется только для TCP-серверов. APK подписан публичным ключом проекта (см. `android-signing/README.txt` в исходниках), поэтому проверяйте SHA-256.

**Что проверено автоматически.** При каждой сборке APK собирается, подписывается и проверяется утилитами Android SDK, а служба VPN (ядро и туннель) тестируется на эмуляторах Android 14 и Android 10: трафик проходит через туннель только пока VPN включён.

**Что автоматически не проверено:** окно приложения на телефоне, кнопка «Подключить», импорт подписки и запуск на настоящем телефоне. Нашли проблему — откройте [issue](https://github.com/sdemanenko764-cmd/VpnSun/issues) со скриншотом или текстом ошибки.

## Возможности

- **Форматы подписок:** VLESS, VMess, Trojan, Shadowsocks (+ плагины), Hysteria2, TUIC, AnyTLS, WireGuard, SSH; ссылки и подписки v2rayNG / Hiddify / Clash / sing-box / Streisand / HAPP.
- **Протоколы и транспорт:** Reality, TLS, XHTTP, WebSocket, gRPC, HTTPUpgrade, H2, маскировка Hysteria (salamander), UDP port hopping, закрепление сертификата, шифрование VLESS.
- **Windows:** режим выбранных приложений через системный прокси (совместимо с zapret), TUN, SOCKS5/HTTP, автообновление, живой список соединений.
- **Интерфейс:** анимированные темы, вкладка «Локации» с избранным и фильтрами, статистика скорости.

## Как собирается

Сборки выполняются автоматически в GitHub Actions из `downloads/Sun-VPN-<версия>-source.zip` (проверяется SHA-256):

- **Windows** — на Windows/MSVC: тесты, переносной EXE и установщик NSIS, проверка установки, обновления и удаления, затем публикация файлов и `latest.json` (его читает автообновление).
- **Android** — на Linux: ядро sing-box 1.12.0 как библиотека (`libbox`, gomobile), приложение Tauri, подпись, проверка APK и тест VPN на эмуляторах.

Сторонние ядра sing-box и Xray — официальные закреплённые версии, их лицензии и исходники включены в сборки.
